# Лабораторная работа №4

## Тема
@Service. Бизнес-логика приложения.

## Цель работы
Разработать сервисный слой Spring Boot приложения,
реализовать управление задачами и взаимодействие
с базой данных PostgreSQL.

## Выполненные задания

### Шаг 1. Разработка бизнес-логики

Реализован класс TaskService.java.

Использована аннотация @Service.

Реализованы методы:
- getAllTasks() — получение всех задач.
- getTaskById() — поиск задачи по ID.
- saveTask() — создание и обновление задачи.
- deleteTask() — удаление задачи.
- findByCompleted() — фильтрация по статусу.

### Шаг 2. Обновление контроллера

Обновлён класс TaskController.java.

Контроллер использует TaskService
для взаимодействия с базой данных.

Реализованы:
- Отображение списка задач.
- Открытие формы создания задачи.
- Открытие формы редактирования задачи.
- Сохранение задач.
- Удаление задач.
- Изменение статуса выполнения.
- Фильтрация задач.

### Шаг 3. Создание представлений

Создан файл task-form.html.

Обновлён файл tasks.html.

В веб-интерфейсе реализованы:
- Форма создания и редактирования задач.
- Кнопка редактирования.
- Кнопка удаления.
- Кнопка изменения статуса.
- Фильтры выполненных и невыполненных задач.

### Шаг 4. Тестирование функциональности

Проведено тестирование через веб-приложение.

Результаты:
- Создание задачи — успешно.
- Отображение задачи — успешно.
- Редактирование задачи — успешно.
- Удаление задачи — успешно.
- Изменение статуса — успешно.
- Фильтрация задач — успешно.

## Результат

Разработан сервисный слой приложения.
Реализовано управление задачами с сохранением
данных в PostgreSQL через Spring Data JPA.

## Вывод

В ходе лабораторной работы изучено применение
аннотации @Service и организация бизнес-логики
в Spring Boot.

Реализовано взаимодействие между контроллером,
сервисным слоем, репозиторием и базой данных.
