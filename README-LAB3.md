# Лабораторная работа №3

## Тема
JPA. Создание сущности и репозитория.

## Цель работы
Изучить использование Java Persistence API (JPA)
для взаимодействия Spring Boot приложения с базой данных.

## Выполненные задания

### 1. Создание JPA-сущности

Создан класс Task.java в пакете:

src/main/java/com/example/demo/entity/

Использованы аннотации:
- @Entity
- @Table
- @Id
- @GeneratedValue
- @Column

Сущность Task содержит следующие поля:
- id
- title
- description
- completed
- deadline

### 2. Создание репозитория

Создан интерфейс TaskRepository.java в пакете:

src/main/java/com/example/demo/repository/

Интерфейс наследуется от JpaRepository<Task, Long>.

Репозиторий обеспечивает взаимодействие
с базой данных PostgreSQL.

### 3. Проверка работы с базой данных

Проверка выполнена через веб-приложение Spring Boot.

Реализованы следующие операции:
- Добавление новой задачи.
- Сохранение задачи в PostgreSQL.
- Получение списка задач из базы данных.
- Отображение задач на веб-странице.

## Результат

Созданы JPA-сущность Task и репозиторий TaskRepository.
Проверено добавление и получение задач из базы данных PostgreSQL.

## Вывод

В ходе лабораторной работы изучены основы JPA
и Spring Data JPA. Реализовано взаимодействие
Spring Boot приложения с базой данных PostgreSQL.
